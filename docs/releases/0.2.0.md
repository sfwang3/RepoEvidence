# RepoEvidence 0.2.0

This release consolidates the Interactive Workspace and the evidence
presentation cleanup around the existing RepoEvidence contracts. It does not
add an automatic fixer, a monitoring service, or a new machine schema.

## Highlights

- Interactive Workspace for human-first repository inspection and recovery.
- Source, runtime, report, and reconciliation status ledger with clearer
  snapshot and freshness presentation.
- Contextual operations that explain the next safe action for each state.
- Live English / 简体中文 language switching with persisted user preference.
- Improved terminal UX for interactive TTYs, plain output, narrow terminals,
  and non-interactive automation.
- Offline HTML report freshness manifest for report provenance.
- Existing one-shot CLI commands remain available for scripts and CI.

## Compatibility

- Existing `scan`, `verify mysql`, `reconcile`, and `report` subcommands are
  preserved; `inspect` and `workspace` are available alongside them.
- Evidence, verification, reconciliation, and report machine schemas remain
  unchanged.
- The package continues to require Python 3.12 or newer.

## Safety

- Workspace startup performs no source scan, target-project execution, runtime
  verification, or database mutation.
- MySQL verification remains explicit, environment-configured, metadata-only,
  and read-only. It does not read business rows or store credentials in user
  settings.
- Static inspection, reconciliation, and report generation remain offline and
  do not execute the target repository.

## Known limitations

- Interactive release validation has been performed primarily on Linux/WSL;
  native Windows/macOS interactive manual validation remains pending.
- A real MySQL successful interactive end-to-end acceptance was not completed
  before this release. Fixture, headless, failure-recovery, and machine
  contract tests cover the current path.
